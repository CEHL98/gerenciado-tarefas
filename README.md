# 📝 Gerenciador de Tarefas API

API para gerenciamento de tarefas desenvolvida com Spring Boot e banco H2

![Badge](https://img.shields.io/badge/Java-17-%23ED8B00) 
![Badge](https://img.shields.io/badge/Spring_Boot-3.2-%236DB33F)
![Badge](https://img.shields.io/badge/H2-Database-%23CCCC00)

## 📋 Pré-requisitos
- Java 17
- Maven 3.8+
- NetBeans (opcional)

## 🚀 Configuração Rápida

```bash
# Clonar repositório
git clone https://github.com/CEHL98/gerenciado-tarefas.git
cd gerenciado-tarefas

# Build e execução
mvn clean install
mvn spring-boot:run
